# P0-0.5｜质量门、儿童安全、跨端与试点验证计划

- 版本：P0-0.5 / 0.1.0
- 状态：测试策略与验收门已定义；没有正式游戏可执行实测
- 适用范围：WordQuest 新项目 `infamous-specter`
- 依据：TECH-ARCH-V0.1、P0-0.1 至 P0-0.4、产品总方案 V2

## 1. 验收原则

1. 每一项“通过”必须有测试对象、版本、设备/环境、步骤、预期、实际结果、证据链接和执行人。
2. 文档/Schema 通过不等于代码通过；Mock 通过不等于真实 API 通过；桌面模拟通过不等于真机通过。
3. 未执行标记 `NOT_RUN`；阻塞标记 `BLOCKED`；失败标记 `FAIL`；通过标记 `PASS`。
4. 不允许把未执行项目计入通过率分母后再用“整体基本通过”掩盖。
5. 任何学习证据错误升级、事件丢失、儿童数据越权或删除后复活，均为发布阻断问题。

## 4. 无障碍与输入公平测试

### 4.1 键盘与 DOM

- 全流程可用 Tab、Shift+Tab、方向键、Enter、Space、Esc（适用时）完成。
- 焦点可见、顺序稳定、弹窗焦点可回收；不发生键盘陷阱。
- 所有 Canvas 核心动作必须有 DOM/键盘等价入口；拖动必须有点击或键盘替代。
- 错误、成功、进度、暂停和重要状态有可读文本，不只靠颜色/动画/音效。
- 自动化执行 axe-core 基础检查；人工验证关键流程和动态状态。
- 目标以 WCAG 2.2 AA 为检查参照；工具扫描通过不能单独证明合规。

### 4.2 读屏

- 至少验证 NVDA + Windows Chrome/Edge、VoiceOver + iOS Safari；Android TalkBack + Chrome 作为移动补充。
- 词库选择、任务提示、输入、提交、结果反馈、暂停/退出、错误恢复均可读可操作。
- 游戏画布中的关键状态有 DOM live region 或等价语义输出。
- 若某款玩法不能提供可用读屏路径，先重构为 DOM/SVG 等价交互或调整玩法，不允许豁免。

### 4.3 减少动态效果与公平

- `prefers-reduced-motion` 和产品内静态模式不隐藏信息、不改变正确答案、不降低奖励/学习权益。
- 慢速/暂停模式使用统一逻辑状态，不通过降低倒计时来惩罚用户。
- 键盘、读屏、触控和鼠标输入相同的语义动作，在相同任务与认知支持下产生相同证据上限。
- 不采集原始键盘/触控时序，不将点击速度、反应时长、拖动精度用于能力判断。

### 4.4 中文输入法（C3）

候选实测组合：Windows 搜狗拼音、Windows 微软拼音；Android 搜狗输入法、百度输入法（具体版本和设备需记录）。至少两款国产输入法必须通过。

测试：compositionstart → 候选选择 → compositionend → 用户主动提交；中途退格、切换大小写、候选上屏、输入法弹窗遮挡、网络中断、重复提交。组合态未结束不得判错或消耗 attemptIndex。

## 5. 性能与资源门

采用 TECH-ARCH-V0.1 的候选预算：

| 指标 | 目标门槛 | 测量方式 |
|---|---:|---|
| 应用壳 JS gzip | ≤200 KB | 生产构建产物统计 |
| 单款游戏增量 JS gzip | ≤450 KB | 单游戏动态分包统计 |
| 首屏可交互 | ≤3 秒目标 | 真实设备、缓存冷/热两组 |
| 低端设备稳态帧率 | ≥30 FPS 目标 | 目标低端 Android 真机采样 |
| 内存 | 单局无持续增长 | 连续进入/退出同一游戏至少 10 轮，记录 heap/纹理/音频 |
| 资源释放 | dispose 可重复调用且不残留 | 监听器、计时器、音频、纹理和 DOM 节点检查 |

测试需记录设备、网络、构建 SHA、浏览器版本、冷/热缓存、测量时长和 trace。超预算必须先定位原因并提出优化；若申请调整门槛，必须升级性能预算版本并记录理由，不能静默放宽。

## 6. 离线、本机恢复与同步

| 测试组 | 场景 | 预期 |
|---|---|---|
| OFF-01 | 首次在线安装 PWA | 应用壳、manifest 和必要静态资源安装成功 |
| OFF-02 | 已安装但未下载词包时断网 | 明确提示无法开始该词包，不显示“离线可玩” |
| OFF-03 | 已下载且版本兼容的词包断网 | 允许本地练习，清楚标记 local/provisional |
| OFF-04 | 断网完成任务后恢复网络 | 事件暂存并按原 eventId 幂等补传 |
| OFF-05 | 补传期间重复请求 | 不重复增加尝试、证据、权益或奖励 |
| OFF-06 | 进行中刷新/关闭/崩溃 | 从兼容快照恢复，或明确说明无法恢复，不静默丢失 |
| OFF-07 | 内容包版本更新 | 旧会话继续使用原版本；新会话使用新版本 |
| OFF-08 | IndexedDB 配额不足/损坏 | 事务失败可见，原有可恢复数据不被覆盖 |
| OFF-09 | 删除档案后仍有离线待同步事件 | 事件被删除状态过滤，不得复活数据 |
| OFF-10 | 两台设备登录同一档案 | 仅在账号、授权、冲突策略和真实同步实现通过后才宣称同步 |

T1 的 app-shell 离线重开不覆盖 OFF-02 至 OFF-10。

## 7. 儿童隐私与安全

### 7.1 默认不采集

真实姓名、学校、班级、精确位置、通讯录、原始键盘时序、原始触控时序、与学习目标无关的麦克风/摄像头内容、公开社交关系。

### 7.2 必须有字段级数据清单

每个字段写明：名称、用途、来源、必需性、敏感/儿童信息判断、存储位置、访问角色、保留期限、删除方式、离线补传处理、日志/诊断限制。

`docs/quality/privacy-data-inventory.template.csv` 是待产品/合规确认模板。保留期限和数据地域未获确认前不得上线对应采集。

### 7.3 删除与回滚演练

- 本机档案删除：IndexedDB、Cache Storage、导出文件和待同步队列均按范围处理。
- 服务端删除：主库、索引、缓存、对象存储和备份保留策略可审计。
- 删除后旧 token、cursor 和离线事件不得恢复已删除数据。
- 内容包撤回：阻止新会话下载/启动；旧版本标记撤回；记录影响范围和回滚版本。
- 权益撤销与内容包撤回不得删除无关的本地个人数据。
- 监护人授权、撤回、导出和删除流程需有真实授权测试；未确定身份模型时不接入儿童云档案。

## 8. C1–C6 逐项测试门

### C1｜机关/路线与语言因果

- 每个机关/路线类型都有唯一语言输入、规则判断、状态变化和 replay 事件。
- 清单覆盖率 100%。
- 固定错误输入触发正向语义状态变化次数为 0。
- 同 seed + 同 logicVersion + 同 action 序列的状态回放完全一致。
- 随机输入若恰好是正确答案，只能通过正常判题路径成功，不能绕过判题。
- 无语言因果链的机关删除或降级为纯装饰。

### C2｜语义消除（G04）

- 只有玩家主动提交且判定正确的语义动作能解锁/产生语言事件。
- 级联消除只能清理已解锁区域，不能凭级联生成新 StudyEvidence。
- 支援题最高 E1；支援不代替玩家作答。
- 错误代价局部、可逆、非羞辱、上限固定。
- “躺平对照”只用于版本/设计评估，禁止用于个体在线惩罚。
- 未完成专项盲测和反事实回放前，G04 不进入 P3。

### C3｜拼写矿车

- accepted variants 单点维护，词包版本固定。
- 先判后演；错误答案不触发成功动画/正向路线。
- IME 组合态不判题、不消耗尝试。
- 离线任务携带 contentPackVersion，未来服务端按对应版本重判。

### C4｜侦探城/线索地牢

- G08 对比固定易混词组，G09 从多候选中按线索推断。
- G09 初中版三条线索可自由顺序查看；小学高年级版另行验证两线索引导。
- 每个候选集非空、目标存在；所有线索完成后唯一目标可被推出。
- 线索组合不能只有重复信息；对比理由有词义/词形/发音依据。
- 换词/放弃部分推理产生 `abandon_partial`，按规则限制同会话次数。

### C5｜动作公平

- 相同语言答案与认知支持，在不同输入设备下证据等级一致。
- 慢速/暂停/静态模式不降低学习权益。
- inputError 与 languageIncorrect 分离。
- 不存储原始输入时序；原始时序不得进入推荐、复习、画像或证据计算。

### C6｜路线收益

- route_bonus 只能生成 ProgressEvent/GameEvent。
- route_bonus 进入 StudyEvidence 的次数必须为 0。
- 钥匙、收藏、装饰、支线和地图解锁只属于游戏表现/结构奖励。

## 9. 试点与统计预注册

### 9.1 形成性可用性试玩

- 目标年龄段分开进行；每个目标年龄段每轮建议 6–10 人。
- 目标：发现规则理解、操作卡点、退出原因、求助点、音频/输入问题。
- 形成性试玩不能证明学习效果，不能宣传记忆效率提升。

### 9.2 学习效果对照

- 游戏练习组与等时长非游戏练习组比较。
- 尽量控制初始词汇水平、词汇难度、学习时长、提示条件和复测间隔。
- 分别报告即时、D+1、D+7、跨玩法迁移结果。
- 样本量需按预期效应、方差、显著性水平和统计功效事先计算；没有功效分析不得写“有效”。
- 指标至少包括首玩理解、首局完成、自愿重玩、五维无提示首答、跨玩法迁移、支援路径退出率和公平性。
- `pilot-preregistration.template.json` 必填字段未填写并时间戳锁定前，不启动学习效果试验。

### 9.3 停止线

任一情况触发暂停并调查：
- 儿童数据越权、泄露、未授权共享或删除后复活；
- 客户端伪造/错误升级 E0–E3；
- 核心任务因设备/输入法/无障碍模式不可完成；
- 游戏状态或学习事件不可复现、丢失或重复计数；
- 出现羞辱、惩罚性连续登录、付费复活或公开儿童成绩；
- 关键假设在预注册分析中未达到预设门槛。

## 10. 测试报告模板

每条测试必须填写：

`testId / requirementId / buildSha / environment / device / browser / dataFixture / steps / expected / actual / status / evidenceLink / defectId / tester / executedAt`

不允许只提交截图而没有构建版本和测试步骤。自动化通过、人工通过、真机通过分别记录。

## 11. P0-0.5 当前执行结论

- 测试计划、质量门、设备矩阵、隐私清单字段、试点预注册要求和停止线已定义。
- 没有正式游戏、真实 API 和 Learning Core，因此本文件中的运行时、真机、读屏、性能、删除演练和学习效果测试均为 `NOT_RUN`。
- 不得把 P0-0.5 文档完成写成产品质量门已通过。
