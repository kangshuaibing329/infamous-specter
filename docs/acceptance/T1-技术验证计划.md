# T1 项目骨架与技术可行性验证

- 版本：T1-SPIKE-0.1
- 分支：codex/t1-project-skeleton
- 状态：代码样板已提交；自动化执行结果待 GitHub Actions 回传
- 范围：React、Phaser、统一输入、IndexedDB、本机恢复、PWA app-shell

## 1. 本阶段目标

建立可重复使用的技术底座，验证前端应用壳、游戏画布、统一输入、本机存档和离线应用壳能否在同一个工程中工作。

本阶段不实现正式单词游戏，不连接生产 API，不建立账号、付费、家长管理或云端同步。

## 5. 当前已知限制

1. 当前技术样板只有移动圆点的演示状态，不是正式游戏玩法。
2. IndexedDB 是本机浏览器存储，不代表跨设备同步或云备份。
3. PWA 仅配置应用壳缓存；内容包、音频、图片离线下载策略尚未实现。
4. Phaser 画布本身不是完整读屏界面；目前以 DOM 方向按钮提供替代操作，仍需人工读屏检查。
5. 当前没有正式词库、学习证据、E0-E3、复习调度或服务端权威判题。
6. 目前未生成 pnpm-lock.yaml；首次 CI 安装会解析 package.json 中精确固定的依赖版本，后续应提交锁文件并切换 frozen install。
7. 当前没有真实 iOS/Android 设备测试结果，不得将 Playwright 桌面 Chromium 结果外推为手机真机通过。

## 6. T1 通过条件

- CI 中依赖安装、类型检查、单测、生产构建和 Playwright E2E 全部通过。
- 画布在约定视口正常显示，触控/鼠标和键盘均能驱动同一状态规则。
- IndexedDB 保存、刷新恢复和显式恢复行为可复现。
- Service Worker 已激活，首次在线缓存后可断网重新打开应用壳。
- 无未解释的控制台异常、未处理 Promise rejection 或重复 Phaser 实例。
- 真实设备测试逐项记录；未执行的项目继续保持【未验证】。

T1 通过只代表技术样板具备进入 T2 共享底座深化的条件，不代表产品可发布。
