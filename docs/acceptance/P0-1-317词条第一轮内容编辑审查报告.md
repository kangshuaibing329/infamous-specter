## 3. 系统性问题与修订

### 3.1 英文定义缺失

初始版本中，317 个词条均未提供合格的英文定义：
- 91 个首批样本词条使用了“lemma: 中文释义”占位文本。
- 226 个新增词条的英文定义为空。

本轮已为 **317/317 个义项补充英文定义**，定义由本项目原创编辑，不直接复制词典释义。

### 3.2 词性与例句不匹配

已修订或明确范围：
- `early`：例句中作副词，词性补充 adjective + adverb。
- `alone`：例句中作副词性补语，词性补充 adjective + adverb。
- `until`：例句中引导时间状语从句，补充 conjunction。
- `than`：补充 conjunction / preposition 两种用法。

### 3.3 释义范围与例句不匹配

已收窄的典型词条：
- `about`：当前介词义不再混入“大约”副词义。
- `letter`：当前例句仅覆盖“信”，字母义应单独建 sense。
- `once`：当前例句覆盖“一次”，不混入“曾经”。
- `exercise`：当前例句指练习题，释义收窄。
- `paper`：当前例句指纸张，试卷义应单独建 sense。
- `period`：当前例句指学校课时，释义收窄。
- `current`：当前例句指电流，水流义应单独建 sense。
- `element`：明确为化学元素。
- `atmosphere`：当前例句指大气层。
- `germ`：收窄为病菌。
- `whether`：当前例句仅覆盖“是否”。
- `grow`：当前例句仅覆盖“生长”。

### 3.4 科学准确性

- `density`：将“质量在一定空间内有多少”改为“一定体积内的质量”，修正科学概念表述。
- `bacteria`：明确复数语境，例句补充 microscope。
- `breathe`：修正 noses 的数一致性。
- `chemical`：补充与另一种物质发生反应的上下文。

### 3.5 美式英语口径

manifest 的发音口径为 `en-US`，本轮同步检查词形和例句拼写：
- canteen → cafeteria
- corridor → hallway
- pupil → student
- revise 的当前教学义从“复习”调整为美式常用的“修订；修改”
- neighbour → neighbor
- practise / practising → practice / practicing
- coloured / colourful → colored / colorful
- favourite → favorite
- flavour → flavor

`timetable` 暂时保留为英式补充词，并添加 `british-english` 标签；美式校园场景优先使用 `schedule`。

### 3.6 发音核验

本轮使用 Cambridge Dictionary 核验了以下 6 个重点词条：

| 词条 | 核验/修订结果 |
|---|---|
| address（名词） | 原 IPA 误用了动词读音，修正为 /ˈæd.res/ |
| often | 采用不带 /t/ 的美式主变体 /ˈɑːfən/，记录带 /t/ 变体 |
| read | 明确原形/现在时 /riːd/，过去式 /red/ |
| air | /er/ 与 Cambridge 美式发音一致 |
| herb | 修正为 /ɝːb/ |
| data | 采用 /ˈdeɪtə/ 主变体，记录 /ˈdætə/ 变体 |

发音来源记录：
- [发音与美式英语核验清单](../../content-packs/review/0.2.0/PRONUNCIATION-AND-US-ENGLISH-CHECKS.md)

## 6. 尚未关闭的发布阻断项

1. **教师复核**：317 个词条的词义、词性、例句自然度、翻译、年级适配。
2. **IPA 复核**：剩余 311 个词条逐词对照指定权威词典，并统一多音、多义和地区变体策略。
3. **教材对照**：当前 gradeTags 是候选适配标签，不能宣称已覆盖指定出版社教材或官方考试词表。
4. **音频生产**：317 条音频尚未生成；需要供应商商用授权、文件完整性、音质和听辨验收。
5. **导入器测试**：实际 JSON/CSV 导入、错误提示、版本固定、重复词和异常回滚尚未测试。
6. **游戏运行时测试**：十款游戏的答案唯一性、提示、重试、进度隔离、断网和音频播放尚未验收。
7. **专项教研**：构词任务与 9 组易混词在教师签字前不得开放 G06/G08。
