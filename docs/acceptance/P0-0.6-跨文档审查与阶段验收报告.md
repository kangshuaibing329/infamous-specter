## 3. 多版本词库专项审查

### 3.1 目录覆盖

已经定义六个可扩展系列：

1. 教材同步版；
2. 年级进阶版；
3. 高频核心版；
4. 主题场景版；
5. 阶段复习版；
6. 自定义导入版。

首批内容生产蓝图包含小学高年级衔接、初中核心、基础高频、进阶过渡、校园生活、日常生活、自然科学、易混词复习等八个包方向。

教材同步版先预留人教版、外研版、译林版、北师大版、冀教版五个出版社槽位。它们目前只是内容规划槽位，不代表已核实具体版次或已有词表。

### 3.2 客户端选择规则

客户可以安装多个包；开始一次游戏时选择一个主包和一个范围。选择路径为：

`词库系列 → 具体内容包 → 版本 → 年级/主题 → 单元/词汇范围 → 游戏 → 难度/辅助`

会话固定 `packId + version`。切换包不覆盖其他包的进度。跨包共享学习记录只有在 canonical sense 等价关系经审核后才允许；默认 pack_scoped。

### 3.3 当前限制

目前没有正式可选的已发布词包。所有目录槽位仍为 planned/editorial_planned；必须完成真实词汇、来源、版次、ISBN、音频/例句、版权/许可和教研审核后，才可将状态改为 published 并显示给客户。

## 5. 本轮发现并修复的问题

1. **新旧服务端边界冲突**：产品总方案旧段落曾建议沿用旧 `/api/activity/*`。已在 P0-0 基线中明确新项目使用独立 `/api/v1/*`，旧 API/数据库/游戏代码不继承。
2. **事件来源缺失**：原 OpenAPI 和 Event Schema 未强制客户端事件 `origin=local)。已修正三类事件的 origin 约束。
3. **证据策略版本缺失**：StudyEventIntent 未强制记录 evidencePolicyVersion。已补入。
4. **词包目录状态不一致**：目录允许 preview，但内容包 schema 原先未包含 preview。已统一。
5. **词包家族字段缺失**：API 摘要已有 familyId，内容包 manifest schema 原先未定义。已补入。
6. **发布门不足**：已增加 published 包必须审核批准、来源核验、授权批准、词条/义项/例句/任务审核、资源许可通过等结构约束。
7. **G03 验收文案错误**：修正误写的“房1/房2/房3”，统一为键盘、触控、读屏回归。
8. **跨包学习进度边界不明确**：补充 canonicalSenseId 与 verified 条件，默认仍 pack_scoped。
