# P0-0.2｜多版本词库、导入规范与用户选择设计

- 版本：P0-0.2 / 0.1.0
- 状态：数据模型与选择流程候选冻结；真实教材词包待来源核验
- 目标：同一套游戏支持多教材、多年级、多类型词库，客户在开始游戏前自行选择，不为每套词库复制游戏。

## 1. 产品裁决

词库从单一教材列表升级为 **Content Pack（版本化内容包）**。一个内容包代表一套有明确来源、适用人群、版本和审核状态的词汇内容。游戏只消费统一的词条/义项/任务合同，不关心词库来自哪家出版社或哪类主题。

用户可以安装/拥有多个内容包；每次游戏会话固定选择一个主内容包和一个明确范围。切换内容包不覆盖其他包的学习记录。未经审核的词包不显示为可玩正式包。

## 2. 首批内容包系列规划

| 系列 | 包版本方向 | 用户选择方式 | 当前状态 |
|---|---|---|---|
| 教材同步版 | 人教版、外研版、译林版、北师大版、冀教版等候选出版社；每个具体册次/版次单独成包 | 出版社 → 年级 → 上/下册 → 版次 → 单元 | 计划中；必须取得具体教材信息并逐项核验 |
| 年级进阶版 | 小学高年级衔接、七年级、八年级、九年级；每学期可独立版本 | 学段 → 年级 → 学期 | 编辑中；不宣称完整教材覆盖 |
| 高频基础版 | 入门基础、常用核心、进阶扩展 | 难度级别 → 词包 | 编辑中；需确定词源、词量和审核标准 |
| 主题场景版 | 校园、家庭、饮食、人物、运动、自然、交通、旅行、科技等 | 主题 → 子主题 → 词包 | 计划中；由编辑团队原创组织并审核 |
| 阶段复习版 | 单元复习、学期复习、错词复习、易混词专项 | 选择范围 → 复习类型 | 计划中；基于已审核词条生成 |
| 自定义词库 | 用户导入 JSON/CSV；后续可扩展 XLSX | 上传 → 预检 → 预览 → 确认安装 | 规范待实现；需做本地隐私与格式校验 |

### 2.1 教材出版社槽位（不是已上架词包）

以下是初期内容规划的候选槽位，不代表已确认具体教材、版次、ISBN 或覆盖范围：

- 人教版（PEP）
- 外研版（FLTRP）
- 译林版（Yilin）
- 北师大版（BNU）
- 冀教版（Hebei Education）

具体教材包必须补齐出版社、书名、年级、册次、版次/印次、出版年份、ISBN、单元范围、词条页码或可核验来源、版权/使用许可审查。缺少任一关键来源信息时保持 `draft/unverified`，不得标为 published，不得对客户显示“完整覆盖”。

### 2.2 首批可并行编辑的词包蓝图

1. `foundation-upper-primary`：小学高年级至初中衔接基础包。
2. `junior-secondary-core`：初中核心词汇包，按年级和学期拆分。
3. `high-frequency-starter`：基础高频词汇包。
4. `high-frequency-bridge`：基础到进阶过渡包。
5. `theme-school-life`：校园与学习场景。

这些是内容生产蓝图，不是已经填充或审核完成的正式词表；具体词量、来源和年级适配须在内容生产阶段确定。

## 3. 用户选择流程

### 3.1 标准流程

`进入游戏大厅 → 选择词库 → 选择词库版本 → 选择范围 → 选择游戏 → 难度/辅助设置 → 开始会话`

选择步骤：

1. **选择词库系列**：教材同步、年级进阶、高频基础、主题场景、阶段复习、自定义。
2. **选择具体内容包**：显示包名、年级、册次/主题、版本、词量、音频覆盖、最后更新时间和审核状态。
3. **选择学习范围**：全部词汇、单元/主题、未练词、错词、到期复习词、收藏词。
4. **选择游戏**：只显示当前内容包有足够任务支持的游戏；不支持的维度或任务不硬塞题目。
5. **开始游戏**：会话记录 `packId + packVersion + scope + gameId + logicVersion`，整个会话固定该版本。

### 3.2 选择器状态

- `published`：客户可选择。
- `preview`：仅允许预览/试玩，明确标注非完整正式包。
- `draft`、`unverified`、`rejected`、`retired`：不出现在普通客户选择器。
- 已购买权益仅控制是否可访问对应内容包，不改变词汇判定、提示权益、复习频率或证据等级。
- 同一用户可安装多个内容包；每个游戏会话只绑定一个主包，避免混合来源导致教材进度和复习归属不清。
- 后续若支持跨包混合练习，必须显式创建用户词单并保留每个词的来源包，不得静默合并。

### 3.3 切换与进度隔离

- 切换包不会删除、覆盖或重置其他包的历史记录。
- 进度主键至少包括 `profileId + wordId + senseId + dimension`；若跨包共享学习状态，必须先确认两个包的 sense 完全等价并设置 `progressScope=shared`。默认 `pack_scoped`。
- 同一个拼写在不同义项下必须使用不同 senseId。
- 已开始会话固定内容包版本；后台有新版本时不强制热切换。
- 内容包被撤回时，禁止新会话启动；已进行会话按撤回策略安全结束或转为只读，保留审计记录。

## 4. 版本与来源治理

每个包不可变发布，版本采用语义版本或递增内容版本。更新创建新版本，不覆盖旧版本。

必须保留：
- `packId`、`version`、`schemaVersion`、`contentHash`、`assetManifestHash`；
- 出版社/教材/版次/ISBN/年级/册次/单元（适用时）；
- 每个词条和义项的来源引用、审核状态、审核人/时间；
- 音频、图片、字体和例句的来源、许可、版本、撤回方式；
- 内容包发布、撤回和回滚记录。

## 5. JSON/CSV 导入

首版稳定支持 JSON 与 CSV；XLSX 作为后续便利入口，不作为第一版强依赖。

导入流水线：

`文件读取 → 编码检测 → schema 校验 → ID/引用完整性 → 词义/词性检查 → 资源检查 → 重复/冲突预览 → 人工审核 → 生成不可变版本 → 安装/发布`

失败必须给出行号、字段名、错误代码和修复建议；不允许“导入成功但丢字段”。

| 检查项 | 通过条件 | 状态 |
|---|---|---|
| 多系列 | 至少覆盖教材、年级、高频、主题、复习、自定义六类 | 蓝图已定义 |
| 多版本 | 同一系列可存在多个独立 packId/version | schema/目录已定义 |
| 客户自主选择 | 选择器按 published/preview 状态显示 | 流程已定义 |
| 版本固定 | 会话固定 packId/version | 合同已定义 |
| 进度隔离 | 切换包不覆盖历史记录 | 合同已定义 |
| 导入规范 | JSON/CSV、必填字段、引用校验、错误报告 | schema/模板已定义 |
| 教材真实性 | 具体出版社、版次、ISBN、来源和版权审核齐全 | 未执行；真实词包未发布 |

**结论：多版本词库的产品和数据合同可以进入候选冻结；教材词条不能在教材版本未核验前标为正式。**
