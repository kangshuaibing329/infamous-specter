# ADR-001：T1 技术样板依赖版本

- 状态：T1 候选版本，等待 CI 验证
- 日期：2026-10-31
- 适用范围：当前项目骨架，不构成生产环境长期升级策略

## 决策

| 组件 | 固定版本 |
|---|---:|
| Node.js | 24.22.2 |

## 决策理由

1. Phaser 4.2.1 是技术架构候选稿锁定的游戏运行时版本；T1 直接验证该版本，不复制 Phaser 3 API 示例。
2. React 负责应用 DOM 壳；Phaser 通过 React.lazy 动态加载，避免把游戏运行时直接塞入首屏模块。
3. Vite + vite-plugin-pwa 负责生产构建、Manifest 与 Service Worker 生成。
4. Dexie 作为 IndexedDB repository 的实现层，业务模块不直接散落 IndexedDB 操作。
5. Vitest 验证纯规则；Playwright 验证真实浏览器流程；GitHub Actions 汇总自动化结果。
6. 依赖均使用精确版本号，避免使用 latest 或范围符号造成无意升级。

## 验证与退出条件

- 本 ADR 当前只记录候选依赖组合。
- CI 安装、类型检查、构建和浏览器 E2E 全部通过后，才能将这些版本认定为 T1 可用组合。
- 若某依赖与 TypeScript 7 或 Vite 8 不兼容，优先按官方 peerDependencies 选择兼容的稳定版本，并更新本 ADR。
- 正式冻结前必须生成并提交 pnpm-lock.yaml，后续 CI 改用 frozen install。
